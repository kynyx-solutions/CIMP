# Fonts

Noto Sans Regular and Bold, embedded in server-generated PDFs (application, progress report, chat history, ID cards) so that the rupee sign and accented names render.

- Source: https://github.com/notofonts/notofonts.github.io (fonts/NotoSans/hinted/ttf)
